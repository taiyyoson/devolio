# The Incursion

This is my first post. This is really cool - I'm testing my inline-frontend text editor to write blogs from the website, instead of writing to a file on my local filesystem and then pushing to git. 


This is the story - I've had the idea to build an MCP server for quite a long time (before Roblox Studio ever released their public MCP tooling). I should mention they reached out to the collaborators of an open-source Rust-based MCP tool that was used widely before Roblox Studio had their own. 

I had the code sitting in my homelab local machine, never pushed remotely to Github, because I kind of scaffolded a bootstrap for it and forgot about it. I got the idea for it from my Fastly internship back in Summer 2025 when one of my intern/friends had showed us his Fastly MCP server that had nearly 1k stars. I saw it and saw it as a passion project with real potential.

My takeaway? Time is of the essence. Don't wait. Innovation is a race between those who got ideas from their God. Michael Jackson had to produce his songs sometimes at the dead of the night because he was afraid Prince would steal his songs. Hence Purple Rain.

Obviously, this is a joke. It's a shame, but there's no real resentment. I'm writing this while watching a rendition of Gravity Falls on my old cable TV. Talk about time being of the essence. Nostalgia is a gut punch.
